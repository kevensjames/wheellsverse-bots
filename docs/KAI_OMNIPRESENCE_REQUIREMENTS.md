## Status vocab
`SATISFIED` — implemented at HEAD, covered by a named passing test module, and adversarially reviewed;
**dark and undeployed** (deployment/enablement is a separate operator gate, never implied by this status) ·
`PARTIAL` — implemented in part; the row names precisely what is missing ·
`GAP` — nothing at HEAD implements it ·
`DEFERRED` — an operator or external gate blocks it; a code seam may exist but the requirement cannot be
met at HEAD · `N-A` — not a buildable/testable artifact.

**Gate legend:** `[G:STAGING]` no isolated Railway staging environment exists (blocks hosted-edge cert and
any authority enable) · `[G:OPS]` operator-only act (credential/data provisioning, restricted-security
activation, production merge/deploy go-ahead) · `[G:SPEC90]` §90 spec tail truncated.

**Never-satisfied rule:** a gated or not-run item is never marked SATISFIED. Nothing in this ledger
asserts deployment, enablement, or production certification of this build.

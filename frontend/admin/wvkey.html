Common commands

One-time setup

# Already done 2026-05-14. Init creates the vault and
# stores master password in the Keychain.
wvkey init

Inspect

wvkey list                 # names only
wvkey get OPENAI_API_KEY     # value to stdout
wvkey list | wc -l         # key count

Mutate

wvkey set KEY "value"
wvkey set KEY -         # read value from stdin
wvkey unset KEY

Run a bot with injected secrets

wvkey run -- python -m narai.bot
wvkey run -- ./launch.sh

Uses os.execvpe: signals pass through cleanly to the child, no wrapper layer.

Re-import from .env (re-runs are non-destructive)

wvkey migrate-env /Volumes/Wheellsverse/wheellsverse_bots/.env

Disaster recovery

wvkey export ~/secure/wvkey-backup-$(date +%Y%m%d).env
# PLAINTEXT — copy to encrypted external storage immediately.
wvkey rotate              # re-encrypt under new master password

Why local-only

The vault and master password never leave this Mac mini. If Railway, Supabase, or any cloud component is compromised, the vault is unaffected.

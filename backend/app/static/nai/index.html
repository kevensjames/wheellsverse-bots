Why this exists

It was a Tuesday. 40 minutes into debugging a Stripe webhook. I asked ChatGPT for a second opinion. The reply: "You've reached your GPT-4 limit. Try again in 3 hours." I was already paying $20/mo.

So I built the chat I wished I had:

  • Two models, one chat. Switch between GPT-4o and Claude mid-conversation. Same thread, same memory, same bill.
  • Real memory across chats. Structured. It knows which repo you're on, which clients bill hourly, which dumb ideas you regretted last week — not the two-sentence "user is a developer" version.
  • 200+ tools that actually execute. Notion, Linear, GitHub, Slack, Calendar, Stripe — via Composio. Real round-trips, not "we can describe an API call you might want to make."
  • No throttle limits. That's the whole point.

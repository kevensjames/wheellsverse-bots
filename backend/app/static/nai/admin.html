Plans · KAI's long-term goals

            

              —
              
              
            

          

          

            KAI breaks a goal into ordered steps; you approve, then run them one
            at a time. A failed step blocks the plan and KAI can propose a
            revision. Every action is audit-logged (scope planning.*);
            set KAI_SCOPE_PLANNING=1 to enable.
          

          

            
            
            
          

          

            🧬 Self-improvement: name a capability and KAI scouts
            GitHub for the best safely-adoptable repo (license + maintenance
            checked), then drafts an integration plan that uses it as a
            reference design. Nothing is installed or run — approve the
            draft to authorize KAI's normal audited steps.

Browser · KAI computer-control (read + propose)

            

              —
              
            

          

          

            v1 envelope: KAI navigates allowlisted domains and
            READS them; write actions (click/type/submit) are proposed only,
            never executed. Kill-switch KAI_BROWSER_ENABLED, scope
            KAI_SCOPE_BROWSER, SSRF-guarded; every action logged below.
          

          

          

            
            
          

          

        


        

          

            
Execute write sequence · envelope B (approved)

          

          

            Operator-only: runs a sequence of write actions on one allowlisted
            page, then closes. Requires KAI_BROWSER_WRITE_ENABLED=1.
            KAI proposes (see log); you execute here. Actions = JSON array of
            {type, selector, value} (type ∈ click/type/submit/select).
